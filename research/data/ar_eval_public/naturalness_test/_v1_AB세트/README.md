# 자연스러움 블라인드 테스트 (립, 20쌍)

## 평가자에게 부탁할 것 (3명 이상, AR을 만들지 않은 팀원)
1. 이 PC에서 `naturalness_test.html`을 더블클릭해 브라우저로 연다 (인터넷 연결 없음).
2. 이름을 적고 **안내받은 세트**를 고른다.
   - 평가자 1·3 → **A 세트**, 평가자 2·4 → **B 세트** (A·B를 섞어야 사람별 편향이 줄어듦)
3. 사진 20장마다 ① 실제로 바른 립 / AR ② 자연스러움 1~5점을 누른다 (약 4분).
4. 끝나면 CSV가 저장된다 → 그 파일을 이 폴더의 `results/`에 넣는다.

## 채점
`python research/data/ar_eval_public/naturalness_test/score.py`
→ 맞히기 정답률(95% 범위 포함), 진짜·AR 평균 점수, 평가자별 정답률, 쌍별 결과(`naturalness_by_pair.csv`)

목표 (평가 기준 v1.1 제안, 검증 전): **AR 평균 ≥3.5점, 정답률 ≤65%**

## 구성
- 사진: Kaggle "Makeup Detection Face Dataset"(= 받은 zip, CC BY-NC-ND 4.0)에서 고른 립 20쌍
- 진짜: 실제로 바른 사진의 입술 부분 / AR: 같은 데이터의 맨얼굴 사진에 **앱 립 셰이더**(faceTrackerHtml.ts)를
  오프라인으로 입힌 것 (헤드리스 Chromium + SwiftShader, 폰 카메라 경로 아님)
- AR 색 = 실제 사진의 입술 평균색 (제품 hex 없음), 제형 = 반짝임 비율로 추정 (매트/새틴/글로시, 사람 확인 전)
- A 세트: 사람 10명은 진짜, 다른 10명은 AR / B 세트: 반대. 한 세트 안에서 같은 사람은 한 번만 나온다
- 정답(`key.csv`)은 HTML에 들어 있지 않다. 평가자에게 key.csv를 보여 주지 않는다

## 라이선스
CC BY-NC-ND 4.0 → AR을 입힌 이미지는 변형물이므로 **팀 내부 평가에만** 쓰고 인터넷·발표 자료·드라이브에 올리지 않는다.
결과는 숫자(정답률·평균 점수)로만 보고한다.
