# 자연스러움 블라인드 테스트 (v3: 립 쌍 6장 + 4부위 AR 4장)

## 평가자에게 줄 것
- `naturalness_test.html` **하나만** 보냅니다. 더블클릭하면 브라우저로 열리고, 인터넷이 필요 없습니다.
- `key.csv`는 정답표라서 **절대 주지 않습니다.**
- 사진은 CC BY-NC-ND 라이선스라 팀 비공개 채널에서 내부 평가용으로만 씁니다. 외부 공유나 공개 채널 게시는 하지 않습니다.
- AR을 만든 사람은 평가자로 넣지 않습니다.
- 평가자는 **20명이 목표**이고, 최소 10명입니다(아래 "몇 명 필요한가").

## 테스트 구성
사진 묶음은 20명이고, 한 사람마다 사진이 5장 있습니다.
- **쌍 사진 2장:** 실제 립 화장 사진 1장과, 같은 사람 맨얼굴에 립만 입힌 AR 1장
- **4부위 AR 3장:** 같은 맨얼굴에 립, 파운데이션, 블러셔, 아이섀도를 약·중·강으로 입힌 것

평가자마다 서로 다른 10명을 무작위로 뽑습니다. 같은 사람은 한 번만 나옵니다.
- **6명은 쌍 사진입니다.** 실제 3장과 AR 3장으로 항상 반반입니다. 실제/AR 맞히기는 이 6장으로만 계산합니다. 실제 사진이 립만 바른 사진이라, 4부위 AR과 섞으면 "눈 화장 있으면 AR"로 맞혀 버리기 때문입니다.
- **4명은 4부위 AR입니다.** 약, 중, 강이 한 장씩 나오고, 마지막 한 장은 무작위입니다.

장마다 묻는 것:
1. 실제/AR
2. 자연스러움 1~5점
3. 어색한 부위(입술·피부·눈·볼·없음)와 이유(색·경계·질감)

## 결과 받기
평가자는 마지막 화면에서 둘 중 하나로 보냅니다.
1. **결과 복사** 버튼 → 디스코드에 붙여넣기
2. **결과 CSV 저장** 버튼 → 다운로드 폴더의 `naturalness_이름.csv` 첨부

받은 결과는 `results/` 폴더에 넣습니다.
- 파일로 받은 경우: 그대로 넣습니다.
- 붙여넣은 글로 받은 경우: 메모장에 붙여 `.csv` 또는 `.txt`로 저장해 넣습니다.
- 디스코드가 긴 글을 `message.txt`로 바꿔 보낸 경우: 그 파일을 그대로 넣습니다.

## 채점
```
python score.py
```
같은 폴더의 `zone_change.csv`(4부위 AR 부위별 변화량)와 `lip_4metrics_by_pair.csv`(립 쌍별 색·질감·위치 수치)를 자동으로 연결합니다.

출력:
1. 실제/AR 맞히기 정답률 (목표 ≤65%)
2. 자연스러움 점수 (목표 AR ≥3.5), 어색한 부위와 이유
3. 4부위 AR 약·중·강 단계별 점수와 부위별 어색 비율
4. **컴퓨터 수치 구간별 "그 부위가 어색하다"는 응답 비율.** 비율이 급히 오르는 구간이 합격선 후보입니다. 예: 블러셔 변화가 3을 넘으면 '볼 어색'이 급증 → 블러셔 합격선 3.

결과 파일:
- `naturalness_by_image.csv`: 사진별 결과
- `responses_all.csv`: 정답을 붙인 전체 응답 (엑셀 분석용)

목표값은 평가 기준 v1.1 제안이며 아직 검증 전입니다.

## 몇 명 필요한가
- **실제/AR 정답률:** 평가자 10명이면 쌍 판단 60개로 오차가 약 ±12%p입니다. 20명이면 120개로 약 ±9%p입니다.
- **단계별 표:** 20명이면 단계마다 약 27개 판단이 모입니다.
- **수치 구간별 표:** 구간마다 10개 이상이 모여야 의미가 있습니다. 그래서 20명이 필요합니다.

## 한계 (보고서에 함께 적을 것)
- 실제 사진은 립 화장뿐입니다(Kaggle Makeup Detection Face Dataset 샘플). 그래서 4부위는 "실제 화장과 비교한 정답률" 없이 점수와 어색 응답만 측정합니다.
- 4부위 색은 임의 팔레트입니다. 립은 실제 사진 평균색, 파운데이션은 본인 피부톤, 블러셔·아이섀도는 정해 둔 팔레트이고, 제품 hex가 아닙니다.
- 사진 속 인물은 대부분 동유럽 여성입니다. 한국인 피부톤 결과는 팀 촬영으로 따로 확인해야 합니다.
- PC 오프라인 렌더이고, 앱 카메라 화면이 아닙니다.

## 사진을 바꿔 다시 만들기 (`../tools/`)
1. `make_meta_full.py RAW` → `make_meta_levels.py RAW`: 단계별 색·강도 표
2. `render_full.py --raw RAW --meta meta_levels.csv --out OUT`: 4부위 AR 렌더
3. `zone_change.py --raw RAW --ar OUT --meta meta_levels.csv --out zone_change.csv`: 부위별 변화량
4. `pool.csv`(person,real,ar,full1,full2,full3) → `build_test.py pool.csv . --per-rater 10 --full 4`
