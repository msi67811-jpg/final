# 자연스러움 블라인드 테스트 (v2: 무작위 10장)

## 평가자에게 줄 것
- `naturalness_test.html` **하나만** 보냅니다. 더블클릭하면 브라우저로 열리고, 인터넷이 필요 없습니다.
- `key.csv`는 정답표라서 **절대 주지 않습니다.**
- 사진은 CC BY-NC-ND 라이선스라 팀 비공개 채널에서 내부 평가용으로만 씁니다. 외부 공유나 공개 채널 게시는 하지 않습니다.
- AR을 만든 사람은 평가자로 넣지 않습니다.

## 테스트 구성
- 사진 묶음: 20명 × (실제 화장 사진 1장 + 같은 사람 맨얼굴에 입힌 AR 1장) = 40장
- 평가자마다 서로 다른 10명을 무작위로 뽑습니다. 그중 5명은 실제 사진, 5명은 AR 사진입니다. 같은 사람을 두 번 보지 않습니다.
- 장마다 묻는 것: ① 실제/AR ② 자연스러움 1~5점 ③ 어색한 부위(입술·피부·눈·볼·없음, 여러 개 가능)와 이유(색·경계·질감, 여러 개 가능)
- 평가자는 5명 이상을 권장합니다. 5명이면 판단 50개로 정답률 오차가 약 ±14%p입니다.

## 결과 받기
평가자는 마지막 화면에서 둘 중 하나로 보냅니다.
1. **결과 복사** 버튼 → 디스코드에 붙여넣기
2. **결과 CSV 저장** 버튼 → 다운로드 폴더의 `naturalness_이름.csv` 첨부

받은 결과는 `results/` 폴더에 넣습니다.
- 파일로 받은 경우: 그대로 넣습니다.
- 붙여넣은 글로 받은 경우: 메모장에 붙여 `이름.csv`(또는 `.txt`)로 저장해 넣습니다.
- 디스코드가 긴 글을 `message.txt`로 바꿔 보낸 경우: 그 파일을 그대로 넣습니다.

## 채점
```
python score.py
```
출력: 맞히기 정답률(목표 ≤65%, 50%에 가까울수록 AR이 진짜와 구분 안 됨), AR 평균 점수(목표 ≥3.5),
AR 사진에서 어색하다고 고른 부위·이유 비율(실제 사진에서 나온 비율이 기준선), 사진별 결과 `naturalness_by_image.csv`.
목표값은 평가 기준 v1.1 제안(검증 전)입니다.

## 4부위 사진으로 다시 만들기
1. 사진을 `hw01_raw` 형식으로 둡니다: `pNN_day_00_<제품>_0.jpg`(맨얼굴), `..._3.jpg`(풀메이크업), `meta_full.csv`(name,bare,lip,lip_tex,found,blush,eye,eye_tex — 실제 바른 제품 색 hex).
2. `python ../tools/render_full.py --raw <폴더> --out <AR폴더>` → 4부위 AR 렌더
3. `pool.csv`(person,real,ar)를 만들고 `python ../tools/build_test.py pool.csv . --per-rater 10` → 새 HTML과 key.csv
